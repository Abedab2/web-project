About this session

We'll solve questions from the 2024 and 2025 exams about useState, events and props. Bring a laptop with VS Code and a working React project. We code together and compare solutions.

Agenda

  • 19:00Quick recap: useState and event handling
  • 19:20Exam 2025, question 3: shared state between components
  • 20:00Short break
  • 20:10Exam 2024, questions 1–2: lists with map and key
  • 20:45Open questions and tips for the exam

Before you come

  • Review lectures 6–8 (state, events, lists)
  • Install Node.js and VS Code
  • Try exam 2025, question 3 on your own
